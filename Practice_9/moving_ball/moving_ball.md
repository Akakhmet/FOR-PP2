# Moving Ball Game 🔴

Interactive Pygame project featuring a boundary-constrained moving ball.

## Features
- Red ball (radius 25) on white background
- Arrow key movement (20px per press)
- Automatic screen boundary checking
- 60 FPS smooth rendering

## Controls
| Key | Action |
|-----|--------|
| ↑ ↓ ← → | Move ball |
| Q / ESC | Quit |

## How to Run
```bash
pip install pygame
python main.py
